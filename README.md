# AeroSIM

A real-time 3D aerodynamic simulation and virtual wind tunnel environment.

## Vision

AeroSIM is intended to provide:

- 3D aerodynamic geometry design
- Virtual wind-tunnel testing
- Real-time geometry modification
- Aerodynamic visualization
- Numerical flow simulation
- GPU-accelerated computation
- Scientific analysis and validation
